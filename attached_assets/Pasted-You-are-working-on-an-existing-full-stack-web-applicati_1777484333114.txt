  - After 2 hours:

    - It should no longer be visible to users
    - Replace it in UI with:
      "Zdjęcie wygasło"

- Croppola automatically deletes images (TTL-based), but this is NOT enough.
- You must implement APP-LEVEL expiration logic:

  Backend:

  - If expired:
    - Do NOT render image
